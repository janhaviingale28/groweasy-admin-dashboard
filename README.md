GrowEasy AI CSV Importer Dashboard
GrowEasy AI CSV Importer Dashboard is a web application built with Next.js, TypeScript, Tailwind CSS, and FastAPI. It allows users to upload CSV files, automatically map fields using AI, preview imported data, and manage leads through an intuitive admin dashboard.

Technologies
Next.js
React
TypeScript
Tailwind CSS
FastAPI
Python
OpenAI API
Features
AI-powered CSV field mapping
CSV upload and preview
Lead management
Dashboard analytics
Import history
Responsive admin dashboard
Installation
Clone the repository:

git clone https://github.com/your-username/groweasy-ai-csv-importer.git

Install frontend dependencies:

npm install

Start the frontend:

npm run dev

Start the backend:

cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
